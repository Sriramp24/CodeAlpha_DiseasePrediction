# CodeAlpha Task 4: Disease Prediction from Medical Data

## Overview
This project develops a predictive healthcare diagnostics machine learning pipeline that analyzes patient clinical records to predict disease risk across multiple classification algorithms.

## Key Features
- **Comprehensive Clinical Dataset**: Includes key indicators like Blood Pressure, Glucose, Cholesterol, BMI, Insulin, and Heart Rate.
- **Multi-Algorithm Benchmarking**:
  - Support Vector Machine (SVM)
  - Random Forest Classifier
  - Logistic Regression
  - Decision Tree Classifier
- **Clinical Evaluation Metrics**: Cross-Validation Mean Accuracy, Precision, Recall, F1-Score, and ROC-AUC scores.
- **Interactive Diagnostic Function**: Live diagnosis tool providing risk assessment and confidence score for custom patient profiles.

## Project Structure
- `disease_prediction_medical_data.ipynb`: Complete step-by-step Jupyter Notebook containing EDA, preprocessing, model training, benchmarking, and interactive diagnostic demo.

## Getting Started
Open and run all cells in `disease_prediction_medical_data.ipynb`:
```bash
jupyter notebook disease_prediction_medical_data.ipynb
```
